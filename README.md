# Tern

Tern is an open-source, Native AOT command-line tool for Sitecore (SitecoreAI and XM/XP 10.1–10.4).

- It is a **drop-in replacement for the Sitecore CLI**: it uses the same `sitecore.json`, the same Module files, byte-identical Item files and the same stored logins.
- It is **much faster**.
- It adds what the Sitecore CLI lacks: saved Plans you can review before applying them, JSON output for scripts and agents, and item queries.

> Status: design. There is no code yet.

Tern is not affiliated with or endorsed by Sitecore.
